# Class Enrollment Management - User Guide

## Overview
You can now easily manage student enrollments in your course sections directly from the Admin Dashboard.

## How to Use

### 1. Open Admin Dashboard
Navigate to Admin → Class Management

### 2. Locate the Class
Find the class/section you want to manage students for in the class list.

### 3. Click "Enroll" Button
Each class row now has three action buttons:
- **Edit** - Modify class details
- **Enroll** ← Click this to manage students
- **Delete** - Remove the class

### 4. Enrollment Modal
A modal window opens showing:
- **Class Info**: Course name, section, and current enrollment (e.g., 0/40)
- **Two Tabs**:
  - **Available Students**: Students not yet enrolled in this class
  - **Enrolled**: Students currently in this class

### 5. Manage Students

#### Add Students (Available Tab)
1. View all available students
2. Search by name or student ID (optional)
3. Click the **Enroll** button next to any student
4. Success message appears
5. Student moves to Enrolled tab

#### Remove Students (Enrolled Tab)
1. Switch to the "Enrolled" tab
2. Find the student to remove
3. Click **Unenroll**
4. Confirm the action
5. Student returns to Available tab

### 6. Capacity Checking
- **Class Full**: If the class reaches max capacity (e.g., 40), the Enroll button on available students becomes disabled
- **Auto-Update**: Enrollment count updates in real-time
- Shows current enrollment like "15/40"

## Features

✅ **Search & Filter** - Quickly find students by name or ID  
✅ **Tab Organization** - Separate views for available and enrolled students  
✅ **Capacity Protection** - Prevents over-enrollment  
✅ **Real-time Updates** - Changes reflect immediately in class list  
✅ **Confirmation Dialogs** - Prevents accidental unenrollments  

## What Changed?

### Before
- No way to assign students to sections
- All sections showed "0/40" with no enrollment option
- Had to manually manage enrollments elsewhere

### Now
- Click "Enroll" button on any class
- Drag-and-drop style interface
- Real-time capacity tracking
- Immediate updates to enrollment counts
